# School Management System

A full-stack school management system built with React and Spring Boot.

## Project Structure

- `backend/` - Spring Boot backend
- `student-mgmt/` - React frontend

## Requirements

- Java 21 or compatible version
- Maven
- Node.js and npm
- PostgreSQL

## Run Backend

```bash
cd backend
mvn spring-boot:run
```

## Run Frontend

Open a second terminal:

```bash
cd student-mgmt
npm install
npm run dev
```

## Configuration

Configure your database credentials and environment variables locally. Do not commit passwords, email credentials, or API keys.
